## 字段说明

- **Owner**: 当前责任 agent 的代号，一条任务同时只能有一个 owner
- **状态**: 见上方状态机，不允许跳跃状态（比如不能从"未认领"直接跳
  到"完成"）
- **状态历史**: 一行式摘要，不写完整叙事，完整原因去 CHANGELOG 找
- **完成证据指针**: CHANGELOG 条目编号 / commit hash / diff 位置，
  三选一或更多，没有指针不允许标记完成
- **Reopened From**: 只有状态为"复开"时才填，指回原"完成"记录的位置

## 状态变更纪律

- 认领任务：把 Owner 从空/待定改成自己的代号，状态改"已认领"，才能
  开始动手。不允许直接动手不认领
- 发现某条任务 Owner 已经是别人：不直接动手，除非 Owner 方明确移交
- 标记完成：必须同时填上"完成证据指针"，缺证据的"完成"视为不合法
- 触发复开：按上方注释里的两步走，不允许直接覆盖状态字段了事
